# 취약계층 의료지원사업 (충청남도공주의료원)

충청남도공주의료원 관할 지자체 지원금입니다. 경제적 어려움으로 의료 서비스를 받기 힘든 주민에게 의료비를 지원하는 제도입니다.
연간 최대 50만 원까지 지원하며, 치료 필요 시 신청 가능합니다.
주민은 경제적 부담 없이 진료와 약제 지원을 받아 건강을 유지할 수 있습니다.
